Game UI & Art

Jungle Blocks is a hypothetical mobile game that is essentially a clone of the classic game Tetris. I created these mockups as an excercise in creating my take on the UI of a classic game. This also showcases some of my illustration skills. I digitally painted all of the visual assets seen here using my favorite drawing application -- Procreate!!

I also decided to make variants on the in-game resouces counter. I orignally made one to show how much gold a player had in their bank, and included an add button so they could purchase more. I decided I want to explore with different versions of this concept. I really enjoyed how they came out, and I believe it widens the scope of the in-game resources a mobile game could offer.
